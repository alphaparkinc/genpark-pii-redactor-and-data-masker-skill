# GenPark PII Redactor & Data Masker

## Description
Regex and Luhn heuristic PII redaction and tokenization engine sanitizing sensitive emails, phones, IPs, and credit cards.

## Compatibility
- MCP Version: 2025-12-11
- Python: >=3.10 (Standard Library only)
- Supported Platforms: Claude Desktop, Cursor, LobeChat, Smithery, MCP.Directory

## Tools
Refer to `client.py` and `mcp_server.py` for full JSON-RPC tool signatures and parameters.
